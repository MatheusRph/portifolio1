## 🛠️ Como Embarcar Localmente no Projeto

Se você quiser clonar o repositório e inspecionar a sala de máquinas de perto, siga as instruções abaixo no seu terminal.

### 1. Clone o repositório

```bash
git clone https://github.com/MatheusRph/portifolio1.git
```

### 2. Entre na pasta do projeto

```bash
cd portifolio1
```

### 3. Instale as dependências (Abasteça a caldeira)

```bash
npm install
```

### 4. Inicie o servidor de desenvolvimento (Dê a partida)

```bash
npm run dev
```
